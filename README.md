# general

Shared documentation for the TEDI Design System. This repository contains TEDI wiki, architecture decision records and meeting notes.

## Wiki

The [TEDI wiki](https://github.com/TEDI-Design-System/general/wiki) is the developer documentation, organised into two tracks: using TEDI in a project, and contributing to it.

For the design guidelines and component documentation see [tedi.ee](https://www.tedi.ee/1ee8444b7/p/33df89-sissejuhatus), and for component usage, props and live examples see [Storybook](https://storybook.tedi.ee/).

## ADR

Architecture decision records capture significant technical decisions and the reasoning behind them, so the thinking stays available later. Each record states its status, date and decision makers.

Use `ADR/Development/ADR-XXX-<title>.md` as the template and take the next free number.

## Meeting notes

Notes from the recurring design and development meetings, split into `Design/`, `Development/` and `Other/`. `Meeting notes/Development/template.md` is the starting point for a new note.

## Language

The wiki is written in English. The architecture decision records and meeting notes are in Estonian.
